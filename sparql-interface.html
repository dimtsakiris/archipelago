📖 Query Reference — All Available Queries

Every pre-built query, what it returns, and why you'd use it. Click "Load" to put it in the editor above, then Execute.

Query What it returns
Stats by Project Total item count, broken down by AN Project (Amorgos vs Mining in the Cyclades vs any future project).
All Items Every digital object (both datasets), with label, creator, and place. Capped at 100 — raise the LIMIT for more.
All Collections Every collection (19 total: 3 Amorgos + 16 Mining), with its item count.
Amorgos Only Just the original fishing-heritage items (identified as having no AN Project value set).
Mining Only Just the Mining in the Cyclades: Digital Traces items, with place.
Hozoviotissa Items belonging specifically to the Hozoviotissa collection (Q3), with creator.
By Digital Type Count of items per type — Εικόνα (image), Βίντεο (video), Ήχος (audio), 3D. Uses P16.
Videos / Audio / 3D Just the non-photo items, with their external source URL (P15) — the actual Vimeo/Mixcloud/Polycam link.
Creators Every distinct creator name, with how many items each has, most-prolific first.
Places Every distinct place, with item counts.
Keywords Most-used keywords across all items (top 50).
By Documenter Item counts grouped by who documented them (P10) — e.g. Πάρις Τσιριγώτης, Jacob Moe.
Missing Date Data-quality check: items that have no date of creation (P3) recorded at all.
Lookup by Identifier Find the exact Wikibase item for a known source-spreadsheet identifier (P14) — edit the value in the query.
Items by Island Mining-dataset items filtered by place text (example: Milos) — edit the CONTAINS(...) text for other islands.

Property reference: P1 instance_of · P2 creator · P3 date · P4 place · P5 part_of_collection · P6 keywords · P10 documenter · P12 AN Project · P14 identifier · P15 source URL · P16 digital object type. Q1 = digital object, Q2 = collection.
